PowerFolio – Personal Portfolio Template

PowerFolio is a modern, responsive, and fully customizable portfolio template designed to help developers, designers, and students showcase their work professionally.
This demo highlights clean UI, animations, reusable components, and responsive layout.

Features
1.Modern UI/UX with smooth animations
2.Fully responsive design for all screen sizes
3.Reusable components



Tech Stack:
HTML5,CSS3 / TailwindCSS ,JavaScript,React.js



Installation & Setup
1. Clone the repository
git clone https://github.com/Bhavyasrivadapalli/powerfolio.git
cd powerfolio

2. Install dependencies
npm install

3. Run the project
npm start

4. Build for production
npm run build
